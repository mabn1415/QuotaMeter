* 主な変更
- Swift Package、ターゲット、ソース名、アプリ表示、実行ファイル、Info.plist、インストール先をQuotaMeterに統一。
- Bundle Identifier は =local.quotameter.app= ．バージョンは 3.8 / build 38．
- 保存先は =Application Support/AllowanceMonitor= のまま維持。Chromeプロファイル・利用履歴を複製せず再利用する設計。
- 旧UserDefaultsの3キーのみを一度だけ取り込む。新しい設定は上書きしない。旧ドメインは削除しない。
- 新版起動時の旧アプリ検出、新版同士のファイルロック、インストーラの実行中確認を追加。
- 保存先700、新規Nodeファイルumask 077、Swift指示ファイル600。実データへの適用は新版の起動時。
- 診断メッセージのHTTP URL・ホームパスを伏字にし、長さを制限。診断用pageUrlはchatgpt.comのトップだけに限定。
- 起動時に案内・詳細画面を表示し，画面内の 3 手順だけで初回設定を進められるように変更．ログイン中は Chrome の上に「ログイン完了」パネルを表示．
- CDP 操作に不要だったアクセシビリティ設定の案内を削除．
- lockfileを使うnpm ci、空の作業場所からの.app組立、署名検証、インストール前の退避処理を整備。
- =setup.sh= に環境確認，依存導入，ビルド，インストールをまとめた．Xcode が導入済みで Command Line Tools が選択されている場合も，システム設定を変えずビルド時だけ Xcode を使用．
- Timer から起動する =Task= に =[weak self]= を明示し，Swift 5.10 の並行処理チェックによる Release ビルド停止を修正．
- 5 時間枠・週間枠の残量が 50・20・15・10・5・0％ に達した時と，リセット時の macOS 通知を追加．
- 任意設定として ntfy 経由の iPhone 通知，通知先の自動作成，テスト通知を追加．
- QuotaMeter の残量ゲージを表したアプリアイコン，通知先のコピー，ntfy の受付結果表示を追加．
- 通知先の操作欄に，ntfy の導入からテストまでの iPhone 設定手順と App Store リンクを追加．
- メニューバーのポップアップ外をクリックした時に，自動的に閉じるイベント監視を追加．
- ログイン後に Chrome を Playwright 用として起動し直す方式を廃止し，ログインした同じ Chrome へ loopback CDP で接続する方式へ変更．
- README.org、.gitignore、共有用ソース許可リストと検査スクリプトを整備。

* 共有用ファイルの確認
以前作成した =QuotaMeter-v3.1-source.zip= は過去版です．v3.3 の配布には使わず，Git の許可対象ファイルを利用してください．Chrome プロファイル，Cookie DB，利用履歴，診断ログ，ビルドキャッシュ，Xcode 個人状態，=node_modules=，=.app= は共有しません．

展開フォルダの =.build/=、=collector/node_modules/=、=dist/= はローカル検証で生成したものです。公開用ZIPには含めません。生成物には作業環境の絶対パス等が含まれる場合もあるため、フォルダ全体を公開対象としないでください。

許可リストと秘密情報のパターン検査は、未知の形式の秘密や将来追加されるファイルの安全性を証明しません。今後の共有前にも検査と目視確認が必要です。
