* 概要
QuotaMeter は，ChatGPT の日本語の「使用状況」画面から，5 時間枠・週間枠の残量を確認する macOS メニューバーアプリです．OpenAI の公式ツールではなく，承認・提携を受けていません．

Swift の画面と Node.js / Playwright による Chrome 操作を組み合わせています．OpenAI API キーは使用せず，トークン数・API 料金・購入クレジットの残高は計測しません．

* 主な機能
 - メニューバーに 5 時間枠の残量を表示し，詳細画面で週間枠・履歴・概算リセット時刻を確認
 - 標準 3 分間隔で更新し，設定で 1・2・3・5 分から選択
 - オフライン時は取得を休止し，接続復帰後に再試行
 - 専用 Chrome のログイン状態を保持し，通常取得時は最小化して常駐
 - Finder から起動し，必要に応じて Mac ログイン時の自動起動を設定

* 必要環境
 - macOS 14 以降と，ビルド対象に対応する Mac
 - Swift 5.9 以降を含む Xcode または Command Line Tools
 - Node.js 20 以降，npm，Google Chrome
 - 日本語の使用状況画面に両方の利用枠を表示できる ChatGPT アカウントとネット接続

Finder 起動時の Node.js 検索先は =/opt/homebrew/bin/node=，=/usr/local/bin/node=，=/usr/bin/node= です．nvm などでのみ導入した Node.js は自動検出されません．

* ビルド・インストール
プロジェクトフォルダで次を実行します．更新時はアプリと専用 Chrome を終了してください．

#+begin_src sh
./scripts/install-deps.sh
./scripts/build-app.sh
./scripts/install-app.sh
#+end_src

=install-deps.sh= は lockfile に従って依存を導入し，JavaScript テストを実行します．=build-app.sh= は =dist/QuotaMeter.app= を作成し，アドホック署名を検証します．=install-app.sh= は =~/Applications/QuotaMeter.app= に配置して起動します．Node.js 本体と Chrome は同梱しません．

* 初回設定
 1. アプリの初回案内で「設定を完了して開始」を選択
 2. メニューバー →「詳細・設定」→「Chrome で初期設定・再ログイン」を選択
 3. 専用 Chrome で ChatGPT にログインし，設定 → 使用状況で両方の利用枠を表示
 4. 最大約 5 分以内に検出され，メニューバーに残量と取得時刻が表示されることを確認

通常の Chrome とは別プロファイルのため，初回ログインが必要です．Chrome の最小化には CDP を使い，この実装はアクセシビリティ権限を要求しません．

* 起動・終了
インストール完了時は自動で起動します．次回以降は，Finder の「移動」→「フォルダへ移動」で次の場所を開き，=QuotaMeter.app= をダブルクリックしてください．

#+begin_example
~/Applications/
#+end_example

ターミナルから起動する場合は，次を実行します．

#+begin_src sh
open "$HOME/Applications/QuotaMeter.app"
#+end_src

 - 起動後はメニューバーに残量ゲージを表示．Dock に通常のウィンドウは表示しない
 - ゲージ →「詳細・設定」で履歴や設定を開き，「今すぐ更新」で手動取得
 - 終了は「詳細・設定」→「終了」から操作
 - 自動起動は「詳細・設定」の「Mac ログイン時に自動起動」を ON にし，必要なら macOS のログイン項目でも承認

通常利用ではターミナルは不要です．プロジェクトの編集先は =~/Documents/QuotaMeter=，インストールしたアプリの場所は =~/Applications/QuotaMeter.app= です．

* 実装フロー
#+begin_example
Finder / ログイン項目
  → Swift / AppKit がメニューバーに常駐し，SwiftUI で詳細を表示
  → Node.js の常駐ワーカーへ JSON ファイルで更新を指示
  → Playwright が専用プロファイルの Google Chrome を起動・再利用
  → 使用状況画面の表示テキストから日本語の残量・相対時間を解析
  → 最新値・履歴・応答を保存し，Swift が読み込んで表示
#+end_example

Swift は 15 秒ごとに応答と更新時期を確認します．Chrome は通常表示で起動後に最小化し，失敗時には復元・再接続を試みます．内部・非公開 API や，アプリ独自の HTTP サーバーは使いません．取得に失敗した場合は，最後の正常値と取得時刻を保持します．

* 保存先
アプリのデータは次の場所に保存します．

#+begin_example
~/Library/Application Support/AllowanceMonitor/
#+end_example

| ファイル・フォルダ | 内容 |
|-------------------+------|
| chrome-profile/ | 認証情報・Cookie・キャッシュ・ブラウザ履歴などの機密データ |
| config.json | 使用状況画面の URL |
| usage.json / history.jsonl | 最新の取得値・取得履歴 |
| collector-diagnostics.json | 最後の診断結果 |
| worker-*.json / quotameter.lock | ワーカーとの連携・新版の二重起動防止 |

表示設定は UserDefaults の =local.quotameter.app= ドメインで管理します．履歴の自動削除はありません．不要な =history.jsonl= はアプリと専用 Chrome の終了後に削除できます．

* セキュリティ・プライバシー
 - 専用 Chrome はログイン済みアカウントを操作できるため，ソースと依存を信頼できる場合だけ実行
 - プロファイル・履歴・診断・バックアップを公開せず，共有やクラウド同期にも注意
 - 保存先は権限 700，新規 Node.js ファイルは umask 077，Swift の指示ファイルは権限 600 で保護するが，同一ユーザーや管理者のアクセスは防げない
 - 診断中の URL・ホームパスは伏字にするが，完全な匿名化ではないため共有前に確認
 - アプリ独自の広告・解析・外部テレメトリはないが，Chrome は ChatGPT や認証サービスなどへ，依存導入時は npm へ通信
 - 生のページ本文やスクリーンショットを収集結果として保存しないが，Chrome 自身は認証・閲覧情報を保存
 - アプリ独自の暗号化や App Sandbox による隔離はなく，FileVault や画面ロックも併用

アプリの削除だけでは実データは消えません．使用をやめる場合は自動起動を OFF にして終了後，必要に応じて保存先・設定・機密バックアップを削除してください．保存先を削除すると，ログイン状態と履歴も失われます．

* 利用規約・公開時の注意
表示テキストの自動取得には，OpenAI の利用規約にある自動・プログラムによるデータ抽出の禁止条項に関する懸念があります．適用契約と許諾を確認できない場合は，自動取得の使用・配布を保留してください．低頻度の取得によって規約適合が保証されるわけではありません．

* 制限事項・トラブルシューティング
 - 日本語の見出しと「残り N%」の両枠表示が必要で，画面変更や別プランでは取得できない場合がある
 - 残量は定期取得した参考値で，リセット時刻は概算．即時性や課金上の正確性は保証しない
 - Chrome が一時的に前面へ出る場合があり，履歴が大きくなると読込みや描画が重くなる
 - Developer ID 署名・公証は未実施で，Intel Mac や別 OS での動作も未検証

| 症状 | 対処 |
|------+------|
| Node.js が見つからない | 「必要環境」に記載した検索先を確認 |
| 取得モジュールが見つからない | 依存導入後に再ビルド・再インストール |
| CHROME_LAUNCH_FAILED | Google Chrome のインストールと通常起動を確認 |
| PROFILE_BUSY | 同じプロファイルを使うアプリ・手動収集・専用 Chrome を終了して待つ．使用中にロックファイルを削除しない |
| LOGIN_REQUIRED | 詳細画面から専用 Chrome で再ログイン |
| USAGE_NOT_FOUND | 日本語の使用状況画面で両枠を表示し，画面構成の変更も確認 |
| タイムアウト・古い値・! 表示 | 接続・ログイン・最終取得時刻を確認し，再更新 |
| 自動起動しない | 詳細画面の自動起動設定と macOS のログイン項目の承認を確認 |
| インストールが停止する | アプリの実行状態と既存の QuotaMeter.app.previous を確認 |

問い合わせには理由コードと操作手順を添え，プロファイルや設定・履歴全体を添付しないでください．
